# Splunk + Sysmon Detection Engineering

## Overview
This folder contains custom Splunk detections built using Windows Sysmon telemetry to identify suspicious endpoint behavior.
The detections focus on process execution analysis and command-line inspection, commonly used in SOC environments.
A sample incident analysis demonstrates how to investigate alerts generated by these detections.

## Tools & Technologies
- Splunk (Search & Reporting)
- Windows Sysmon
- Windows Event Logs
- SPL (Search Processing Language)

## Detections Included
### 1. Encoded PowerShell Execution
- [Folder: `encoded-powershell/`](encoded-powershell/)
- Detects PowerShell processes launched with encoded commands (`-enc`)
- Uses Sysmon Event ID 1 (Process Creation)
- Includes detection logic, MITRE ATT&CK mapping, and analyst investigation notes


### 2. Hidden PowerShell Execution
- [Folder: 'hidden-powershell'](hidden-powershell/)
- Detects PowerShell executions using hidden window styles (`-WindowStyle Hidden`, `-w hidden`)
- Focuses on stealth execution techniques commonly abused by attackers
- Uses Sysmon Event ID 1 (Process Creation)
- Includes detection refinement based on false-positive analysis


### 3. PowerShell Execution from Suspicious Parent
- [Folder: `suspicious-parent-powershell`](suspicious-parent-powershell/)
- Detects PowerShell launched from unexpected parent processes
- Uses parent-child process analysis for anomaly detection
- Data Source: Sysmon Event ID 1 (Process Creation)
